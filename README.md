# 全能工作台 (All-in-One Workbench)

一个**零依赖、单文件**的个人效率工作台。双击 `index.html` 即可在浏览器中使用，数据保存在本机 `localStorage`，无需后端、无需联网、无需安装。

珊瑚橙主题，移动端 / 桌面端自适应，四合一覆盖日常记录场景。桌面端为**左侧抽屉导航（可收缩为图标栏）**，移动端为**覆盖式抽屉 + 固定底部导航栏**。

> 另提供**可选的云端账号与多设备同步**：部署到 Cloudflare Pages 后，用邮箱 + 密码登录即可把数据存进你自己的 Cloudflare D1（共享 `dev` 库，全部表前缀 `wba_`）。不登录则退回纯本地模式，行为与之前完全一致。

## 功能模块

- **记账**：点「最近记录」右上角 **＋** 图标，弹框录入收入 / 支出（金额、分类、日期、备注），保存后自动关闭；按分类自动生成饼图，预算环实时显示本月预算消耗；支持**按月份 / 分类 / 关键字筛选**；可**编辑 / 删除**每一笔；可**导出 CSV**（含 BOM，Excel 直接打开不乱码）或 **JSON 备份**。
- **习惯**：点「我的习惯」右上角 **＋** 图标，弹框新增习惯（名称 + 颜色）；月历视图展示每日打卡强度（颜色越深打卡习惯越多），可一键打卡；点击日历**任意一天**可弹出该日各习惯的勾选框，方便补打卡 / 取消；连续打卡天数（🔥 streak）自动统计；习惯可**重命名 / 改色 / 删除**。
- **待办**：点「待办清单」右上角 **＋** 图标，弹框添加带日期与优先级（P0/P1/P2）的待办，点击圆圈完成；支持**编辑 / 删除**；顶栏时钟图标会自动汇总今日与逾期待办及未打卡习惯。
- **减脂**：点「历史记录」右上角 **＋** 图标，弹框记录体重 / 体脂 / 运动备注，自动绘制体重与体脂趋势折线图；历史记录可**编辑 / 删除**；同一天再次记录会自动覆盖更新。

## 使用方式

1. 直接双击 `index.html`（或拖入浏览器）。
2. 首次打开会自动写入一组示例数据，方便了解布局；打开左侧抽屉，在底部「数据备份」区点 **清空示例数据** 即可清掉。
3. 点顶栏的**时钟图标**（右上角带数量角标）弹出「今天要处理」清单，汇总当日待办与未打卡习惯，点「完成」可一键勾掉；点「关闭」/ 遮罩 / Esc 收起。
4. 四个模块的**新增都通过点击各卡片右上角的 ＋ 图标**，在弹框中填写并保存；弹框同样可用「关闭」/ 遮罩 / Esc 取消。
5. **云端同步（可选）**：打开左侧抽屉的「云端账号」区 → 登录 / 注册 → 登录成功自动上传一次本地数据；之后每次改动都会**自动静默上传**（防抖 1.5s）。换设备登录同一账号后，可手动「拉取云端覆盖本地」。

## 云端账号与同步（Cloudflare D1）

- **后端**：Cloudflare Pages Functions + D1（共享 `dev` 库，`database_id: 3c83aee3-4645-450b-b50b-6488750deeb4`），全部表使用 `wba_` 前缀（`wba_users` / `wba_sessions` / `wba_userdata`）。
- **安全**：密码使用 **PBKDF2-SHA256**（100k 次迭代 + 随机盐）哈希存储；会话为 **HttpOnly Cookie**（`wba_sid`，7 天有效期），前端 JS 无法读取令牌。
- **本地模式**：不登录 / 无后端（本地双击打开）时自动降级为纯本地存储，不影响任何功能。
- **同步策略**：登录后自动上传一次；本地每次保存后 1.5s 防抖自动上传（仅覆盖自己账号的数据）；「拉取云端」为**整包覆盖本地**，用于换设备恢复。数据键与本地一致（accounts / todos / habits / fitness / budget）。
- **部署**：Cloudflare Pages 构建设置为「无框架」，绑定 D1 → `dev`；首次部署前可在本机跑 `node scripts/init-d1.mjs`（读取 Machine 级 `CLOUDFLARE_API_TOKEN`）预建表，或直接首访由 `_middleware.js` 自动建表。

## 数据存储与备份

- 所有数据仅存于当前浏览器的 `localStorage`，**换浏览器 / 清缓存会丢失**。
- 备份入口已收纳在**左侧抽屉底部的「数据备份」区**（宽屏收起为图标栏 / 窄屏抽屉内同样可用）：
  - **导出 JSON 备份**：完整备份四类数据 + 预算，换设备时可用「导入恢复」还原。
  - **导出 CSV**：仅记账明细，便于在表格软件中做进一步分析。
- 数据累计到 30 条后，页面顶部会提示你备份。

> 隐私说明：本工具不收集、不上传任何数据，全部留在你自己的电脑上。

## 技术说明

- 纯原生 HTML + CSS + JavaScript，**无任何第三方依赖、无构建步骤**。
- 数据层：`localStorage` + 单一 `state` 对象；渲染层采用「数据 → 计算 → 渲染」单向刷新（`refreshAll()` 统一入口）。
- 图表（预算环 / 分类饼图 / 体重折线）均为内联 SVG，无图表库。
- 响应式导航：宽屏为左侧固定抽屉（用抽屉内的收起 / 展开按钮在完整栏与图标栏之间切换，状态本地记忆）；窄屏抽屉变为覆盖层（顶栏汉堡按钮开合，带遮罩），并配固定底部导航栏。顶栏只保留标题与「今天要处理」时钟图标（带未完成数量角标），点击弹出可关闭的待处理清单。数据备份按钮收纳在抽屉底部。
